# 이사돔 핸드폰 (isadom-phone)

여주시농업기술센터 **이사돔** 의 핸드폰용 껍데기입니다.

- `docs/` — 핸드폰에서 여는 페이지 (GitHub Pages: https://utrgh482.github.io/isadom-phone/). 자료는 들어 있지 않습니다.
- `app/` — 그 페이지를 여는 안드로이드 앱(껍데기). GitHub Actions 가 apk 를 만들어 Releases 에 올립니다.

자료(사업·메모·상담 …)는 이 저장소에도, 페이지에도 없습니다. 사무실 PC 의 이사돔 서버와 각자의 핸드폰 안에만 있습니다.
